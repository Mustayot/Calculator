## 版本详情

### v1.0

- **日期**：`2026-09-28`
- **核心逻辑**：
    - 用struct包装要输入的两个数字，在get_numbers函数获得输入的数字
    - 并且检测输入值是否是double类型，是则表明输入良好，否则重置输入状态，清除缓冲区
    - 在get_operation函数中获得要使用的运算方法这里使用了头文件<string_view>寻找输入的值是否在 "+-*/" 范围内

---

### v2.0

- **日期**：`2026-09-28`
- **核心逻辑**：
    - 用map创建字典 map<键类型, 值类型> 字典名称，值类型定为指向double (const Numbers&)类型函数的指针
    - 后面 字典名称[键] = 值，填充初始字典
    - 最后的 字典名称[键] (形参) 中读取字典，根据键去找到值对应的函数指针，把形参传入函数从而调用函数
    - 避免了if-elseif结构，更加简洁

---

### v3.0

- **日期**：`2026-09-28`
- **核心逻辑**：
    - 增强异常处理并且允许用户重复计算
    
---

### v4.0

- **日期**：`2026-09-29`
- **核心逻辑**：
    - 简化main，抽离询问计算和建表填表为独立函数
    - 使用void让函数不返回值，后续直接调用
    
---
